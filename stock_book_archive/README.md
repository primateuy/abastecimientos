Stock Book - Archive
====================

Qué hace
--------
Agrega el campo estándar `active` al modelo `stock.book` (Talonario de Remitos).
Con eso Odoo habilita automáticamente:
- Acción **Archivar / Desarchivar** en el menú de Acción.
- Filtro **Archivado** en las búsquedas (según vista/cliente).

Instalación
-----------
1) Copiar este módulo a tu carpeta de addons custom.
2) Actualizar apps list.
3) Instalar "Stock Book - Archive".
